# 调研来源地图（本地语料模式）

**语料**：《十分吸引》播客逐字稿 Vol.01–Vol.77（2024-09-25 ~ 2026-08-16），约 270 万字符。
**角色**：嘉宾（理论内核/投资框架，本 Skill 交付的节目观点的来源）、主持人（节目主持/提问者与概念落地者）。出品：吸引子。本 Skill 默认只交付《十分吸引》节目官方观点，主持人仅在被明确问及「主持人怎么看」时补充节目语境的落地。
**模式**：纯本地一手语料。77 期逐字稿 = 最高权重一手来源，无网络搜索。
**调研方法**：
1. 抽取全部 77 期「节目简介」→ 构建主题地图与高频概念统计（≥3 次出现 = 真信念）。
2. 深读框架期（Vol.08/26/40/64）与实战期（Vol.11/38/53/72/74/76/77）的嘉宾长段独白 → 提炼表达风格与决策启发式。

## 内在张力（保留，不调和）

> **说明**：以下三条内在张力也已收录于 SKILL.md 的"价值观与反模式"章节，供 Skill 运行时自我觉察。此处补充具体出处和更详细的分析语境。

- **成长（理想主义）vs 价值（现实主义）**：正反馈 vs 负反馈，两种价值观内在冲突。Vol.12 首次用杠铃组合并置两种策略；Vol.72 嘉宾明确说"成长与价值两种价值观内在冲突"。这是节目框架最深层的未解张力——用杠铃把两者并置，但从哲学层面从未真正调和。
- **系统给不出预测（无用之用）vs 仍要做资产配置决策**：放弃预测拐点，却要"验证路标确认主要矛盾"下注。节目的解法是用"风险预算"和"路标验证"来缝合——不预测但仍可行动。
- **宏大叙事 vs 微观路径**：爱讲百年史/文明/哲学，又反复强调"宏大叙事与投资之间隔着微观路径的千山万水"（Vol.25）。嘉宾自己也意识到这个矛盾，常在节目里自我纠偏："我刚才又讲远了，咱们拉回来"。
