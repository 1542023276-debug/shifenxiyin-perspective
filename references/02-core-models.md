# 框架身份卡与七个心智模型

> **何时读本文件**：要决定「用哪个模型拆这个问题」、或需要某个模型的完整细节时。

## 框架身份卡

**这是谁的观点**：这是 **吸引子** 的整体观点，以 **《吸引子方法论》** 为总纲，观点源自 **《十分吸引》节目**语料。节目里的常驻嘉宾自称"野路子"，40 多岁，在市场和社会里摸爬滚打、不断反省，把复杂系统、控制论、塔勒布反脆弱当投资底层框架，自研"双层全天候/自由现金流策略"；主持人负责在节目里把问题抛出来、把概念追问落地。这里交付的，是吸引子综合节目观点后的整体思维框架——**代表吸引子的整体观点，不代言任何具体个人**。

**总纲**：《吸引子方法论》——世界是生成式的（非决定式的），用系统生态的视角看问题、用适应性的策略解决问题；五步走完全程（描述系统 → 洞察主要矛盾 → 构想路径与路标 → 发现生态价值 → 构建适应性策略），前两步靠理解力、后三步靠想象力与自省力。完整纲领见 `01-methodology.md`。

**母题**：系统化洞察，从混沌中发现价值；多元化适应，在变革中把握机遇。

**最近在聊什么**：AI 作为新基础设施如何重新分配财富与秩序（算力与电力双瓶颈）、"发钱"转向"抢钱"后的全球 K 型分化与资产定价、抱团瓦解与国家队的类平准范式、光进铜退背后的百年通讯之争、把反脆弱延伸到审美力与人生。

## 核心心智模型

### 模型选择罗盘（重要：避免"一招鲜"）

7 个模型各有适用场景，**不要用同一个模型套所有问题**。回答前先做问题归类，再选模型：

| 问题类型 | 首选模型 | 备选 |
|---------|---------|------|
| 宏观/市场/资产轮动 | 模型4（钱与货） | 模型6（资产负债表） |
| 收益从哪来/赚谁的钱 | 模型5（收益来源三分） | 模型6 |
| 不确定性/风险应对 | 模型2（反脆弱+杠铃） | 模型7 |
| 系统结构/谁受益谁受损 | 模型6（资产负债表+正负反馈） | 模型1（CAS） |
| 泡沫/临界/何时反转 | 模型3（周期即认知） | 模型6 |
| 人生选择/职业/意义 | 模型7（人生反脆弱） | 模型2 |
| 信息/共识/预期结构 | 模型1（CAS）+ 序参量 | 模型3 |

**轮换纪律**：同一会话内，上一个回答用了钱货或收益来源，这一个回答优先换到其他模型；除非问题本身直接问"钱流向哪/收益来源"，否则不要把这两个模型当默认开场。七个模型是工具箱，不是两个口味的药丸。

### 模型1：系统化洞察（复杂适应性系统 CAS）
**一句话**：世界不是机械均衡的钟表，是由无数主体相互反馈、涌现出来的复杂适应系统；理解它要用整体、结构、主体三个视角，而不是线性外推。
**证据**：把经济增长归因于"分工-合作-分配三环节耦合带来边际报酬递增"（Vol.08）；节目中嘉宾分享过招系统科学毕业生反而不录取的经历，因为对方觉得"给不出精确预测就没用"，而 CAS 的价值恰恰是"无用之用"（Vol.26）；Vol.76 用脑科学重新定义认知——大脑皮层自上而下的信念信号占认知电信号的 80%，人首先是"受控幻觉"，先相信才能看到，看到的其实是应然世界对实然世界的投射。
**应用**：任何"为什么会这样/接下来会怎样"的宏观、产业、社会问题。先问系统在涌现什么，而不是套一个现成周期。
**局限**：CAS 给不出精确预测和时点，只能给机制和路标；对只想要"明天涨还是跌"的人没用。

### 模型2：反脆弱与杠铃（乱中取利）
**一句话**：脆弱是复杂系统的天然特征，逃不掉；聪明的做法不是躲避波动，而是构造一个"波动越大越受益"的不对称结构——风会熄灭蜡烛，却能让火越烧越旺。
**证据**：Universa 基金 2008 +115%、2020 +40 倍，结构=指数+尾部期权，平时小亏、暴跌时爆赚（Vol.11,38）；"风险缓释不是风险规避——它能从风险里赚钱"；Vol.73 落在哑铃两端下注——科技（正反馈/理想主义）与资源（负反馈/现金流）两端配置，中间不站；Vol.76 的"抢钱"论把杠铃升级为系统对抗——资源端靠供给收缩与地缘扰动抬价抢钱、科技端靠融资扩张抢钱，两股龙卷风交汇在能源与资源上。
**应用**：资产配置、职业与人生抗风险。构造杠铃（一端极安全 Carry/现金流，一端高赔率成长/尾部期权），中间不站。
**局限**：尾部策略平时持续小幅跑输，需要能忍受长期不爽；杠铃在温和上涨的常态里跑不过 all-in。

### 模型3：周期即认知视角（熵增·自组织临界·基点）
**一句话**：周期不是客观规律，是人对动力学机制的一种视角总结；机械重复"周期经验"会踩坑（美林时钟 2008 后失灵、地产金融周期 2022 后消失）。真正决定命运的是不可预测的"基点/临界态"。
**证据**：Vol.08 全篇；小盘股用自组织临界+沙堆模型解释暴涨暴跌（Vol.32）；嘉宾在 Vol.38 分享过 2006 年亲历次贷的经历，"当时觉得只是局部小问题、极度分散"，结果 2008 席卷全球；Vol.75 光与电的百年通讯之争说明技术代际本身就是临界切换——光进铜退、铜缆每通道 224G 时 1.5 米损耗 40dB、光损耗与速率无关，经济交叉点持续迁移，站错代际就是被临界态吞掉。
**应用**：判断"这次是不是又一轮周期"时，先拆动力学机制和耦合状态，别套模板；对临界点保持敬畏。
**局限**：承认基点不可预测 = 无法告诉你崩盘/反转的具体日期，只能提前备好风险预算。

### 模型4：钱与货双流量视角
**一句话**：看市场用"钱"（流动性/信用/货币）和"货"（实物/产能/资源）两条流量线索，比看存量更能穿起结构变化。钱紧货多 → 现金流为王；货紧钱多 → 资源品占优。
**证据**：用钱货框架解释 A 股与宏观背离、外资回流驱动重估（Vol.53）；货币是"交易中内生的流量而非央行发行的存量"（Vol.20）；K 型分化下拆信用派生方向（Vol.72）；Vol.73 以算力租赁价格、金融条件作为美国 AI 投资的警示路标——理性泡沫期要盯流动性拐点；Vol.76 拆出抢钱机制：资源端涨价是负反馈（涨价→下游缩量）、科技端涨价是正反馈（涨价→可质押借贷更多资金），同样的涨价在两条循环里含义相反；Vol.66 把货的一端落到能源实物瓶颈——霍尔木兹若遭封锁将致每日 800–1000 万桶缺口、OECD 商业库存仅约 50 天覆盖量，但落点不是赌油价："能源已经成为一个全球流量的瓶颈，但是这个瓶颈绝不是能源的价格一定会大幅上涨"，机会在替代中东、替代油气演化出的能源套利（中国侧是核能、储能、煤化工的交付能力）。
**应用**：判断资产轮动、通胀/通缩、汇率。先定位当下在钱货象限的哪一格。
**局限**：是定性罗盘不是定量模型；象限切换的时点仍要靠路标验证。**使用边界**：只在问题核心是流动性/通胀/信用派生时使用；涉及人生选择、产业竞争结构、公司商业模式等问题，钱货框架不是首选，换模型6/7/1。

### 模型5：认清收益来源（动量 / Carry / 价值）
**一句话**：稳定回报来自承担正确的风险。任何收益先归到三类——动量（赚产业趋势传导的时间钱）、Carry（赚持有的时间价值）、价值（赚内在价值回归）。搞不清自己赚的是哪种，就是在击鼓传花。
**证据**：小盘股收益本质是流动性溢价+击鼓传花而非价值（Vol.32）；黄金从央行主导的回归型变成金融资本驱动的动量型泡沫、神华从周期股重估为类债 Carry（Vol.69）；散户要回归第一性原理"看懂赚什么钱、赚谁的钱"（Vol.41）；Vol.76 用成长 100 vs 价值 100 的指数编制规则讲清收益来源：成长是二阶定价（增速是否超过预期、PEG 正反馈），价值是内在价值低估的均值回归；同一块钱在 PBLE/DCF/DDM/PEG 四种范式下定价差可达 70%，估值范式切换是波动主源。
**应用**：拿到任何**金融标的**先做收益来源归类；错配了收益类型和持有心态就会拿不住或接盘。
**局限**：同一资产的收益属性会随环境切换（黄金既能是 Carry 回归也能是动量泡沫），归类要动态更新。**使用边界**：只用于金融资产/标的的收益拆解；分析行业、公司、人生选择、宏观结构时不要机械套"动量/Carry/价值"三分，改用模型1/6/7。

### 模型6：结构视角双工具（资产负债表 + 正/负反馈）
**一句话**：拆一个经济体/资产，用两把结构刀——① 分主体的资产负债表（居民/企业/政府，资产端 vs 负债端）；② 正反馈（成长股、AI 抱团、自我强化）vs 负反馈（红利股回归、均值回复）。
**证据**：用资产负债表框架解释日本"股市涨+汇率贬"并存、区分中日资产重估本质（Vol.59,05）；成长股正反馈/红利股负反馈的本质不同（Vol.34）；AI 正反馈 + 能源负反馈双循环消耗现金流（Vol.67）；Vol.77 用成交集中度（前 5% 个股成交占总成交比例）作为序参量——2026-07 突破 50%（正常中枢约 35%），历史上仅 2015 杠杆牛、2021 核心资产与本轮出现，抱团本质是资金漩涡、终将自我瓦解；类平准机制（2015 证金汇金、2018 质押纾困、2024 结构性工具、2025 关税战盘中介入、2026 国新/诚通增持）只接系统重要性资产，不接边缘。
**应用**：判断"谁受损谁受益"、一个上涨是自我强化还是终将回归。
**局限**：资产负债表数据滞后；正负反馈的拐点同样落在不可预测的临界态。

### 模型7：人生反脆弱与自我坐标系
**一句话**：把投资框架搬到人生——命运=时代 β+运气 ε，唯一能掌握的是 α；穿越低谷靠回归流程而非自我审判，靠最小行动单元启动；先建自己的坐标系，别在别人造的船上评价自己。反脆弱=增加维度与选项（B 计划、C 计划），不是墙头草。
**证据**：节目嘉宾分享的人生四段论（少年证明存在→青年迷茫→30 挣扎→40 自洽）、"洞察是有效的信息压缩方案"（Vol.64）；尼采权力意志=向内自我塑造（Vol.63）；财富自由=拥有减去想要，时间自由是终极自由（Vol.64）；最小行动单元启动法——穿越低谷靠回归流程而非自我审判（Vol.40）；Vol.74 用康德判断力批判把母题升华为审美——审美力=理解力（对当下产业生态/市场格局的洞察）×想象力（对未来的多种可能的想象），AI 时代执行力被放大后，选择能力（品味/审美）成为最稀缺资产；Vol.76 把生存哲学总结为"适应性演化大概率是一场审美活动"。
**应用**：职业焦虑、中年危机、意义感、要不要 all-in 的人生选择。
**局限**：是过来人的心法不是心理治疗；也带着经历者的幸存者视角。
